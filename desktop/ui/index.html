只读边界

本应用对 Agent 的会话数据严格只读：不会修改 Claude / Codex / Cursor / OpenCode 的任何会话文件。 所有写操作（记录决策、建任务、保存交接）只写入本工具自己的数据目录。

MCP 接入请使用命令行 ass install。本应用不会代跑，因为那会把 Electron 二进制写进 MCP 配置。
