# Agent Session Sync — 安装说明

这是 macOS 应用（Apple Silicon / arm64）。**没有购买 Apple 开发者账号**，所以首次打开需要多一步放行。

## 安装

1. 双击 DMG，把 **Agent Session Sync** 拖进 `Applications`。
2. **先推出 DMG**，再从「应用程序」里 **右键 → 打开**（不要直接双击）。
3. 如果提示「无法验证开发者」：
   **系统设置 → 隐私与安全性 → 下方点「仍要打开」**。
4. 如果提示「已损坏」（只会出现在**旧版/传输损坏**的副本上）：
   说明这个 app 没带上有效签名。请删除后重新下载最新 DMG；仍不行时执行：

   ```bash
   xattr -cr "/Applications/Agent Session Sync.app"
   ```

   然后再右键 → 打开。

> ❌ 不要执行 `spctl --master-disable`。那会关掉整台机器的 Gatekeeper，不安全。

> 判断旧包还是新包：DMG 里的 app 应满足 `codesign -dv` 显示
> `Identifier=com.lihaibo.agent-session-sync` 且 `Sealed Resources version=2`。
> 旧版会显示 `Identifier=Electron`、`Sealed Resources=none`。

## 它做什么

- 读取本机 Claude Code / Codex / Cursor / OpenCode 的**会话历史**并统计（会话、项目、磁盘占用）。
- 按项目聚合：会话列表、任务、项目笔记（决策 / 踩坑 / 约束 / 待办）。
- 生成交接摘要、复制恢复命令、记录笔记、建任务、保存交接记录。

## 只读边界

- 对 **agent 的会话数据严格只读**：不会修改任何会话文件。
- 写操作只写入本工具自己的数据目录：`~/.local/share/agent-session-sync`。
- 所有写操作执行前都会弹确认框，并写明写入目标。

## 系统要求

- macOS 12 及以上
- Apple Silicon（arm64）——本版只打了 arm64
